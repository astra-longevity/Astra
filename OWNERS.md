Chaque zone du dépôt a un manager responsable. Seuls ce manager et ses agents y écrivent.

| Chemin | Manager |
|---|---|
| `literature/` | A2 Literature |
| `data/` | A9 Database |
| `Cargo.toml`, `Cargo.lock`, `clippy.toml`, `rustfmt.toml`, `rust-toolchain.toml` | A10 Rust |
| `crates/`, `scripts/`, `.githooks/`, `.github/` | A10 Rust |
| `interface/` | A11 Interface |
| racine (fichiers non listés ci-dessus), `docs/`, `missions/` | A7 Coherence |
