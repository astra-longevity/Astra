# 0003 — Everything in English

Date: 2026-10-19. Status: accepted. Decided by the president, relayed by A1.

## Context

Until now, the repository's texts were written in French. The president decided that the whole project must be in English, so that it can be read and reused by anyone, and so that there is a single language everywhere.

## Decision

- Everything is in English: docs, data, code, commit messages, messages between agents.
- Use plain language. A technical term that cannot be avoided is explained or added to `docs/glossary.md`.
- The draft marker becomes `[to verify]` (it replaces `[à vérifier]`). It is still forbidden in a delivered file.

This decision replaces the "texts in French" rule of `CONTRIBUTING.md`.

## Consequences

- Every manager translates their own area of the repository.
- A7 checks that no French files are left.
- Existing decisions 0001 and 0002 are translated without changing their meaning.
