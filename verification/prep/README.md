# verification/prep/

Drafts written by Verification before launch (council decision D67: read-only prep).

- Files here may carry `[to verify]` marks. This is the only place in `verification/` where they are allowed.
- Nothing here is sealed or binding.
- At launch each file is either moved to its final folder (with `[to verify]` resolved) or deleted.

Current files:

- `licences.md`: licence checks for GBD disability weights, Retraction Watch, HMD, Eurostat and WHO data.
- `ledger-criteria-template.md`: YAML template for prediction-ledger criteria, with fictional examples (T1, T2, T5).
