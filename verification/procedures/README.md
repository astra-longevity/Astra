# Procedures

How Verification works, written from the founding-council decision log
(`docs/decisions/founding-council-log.md`). Each rule cites its decision id.
Rules not yet decided are listed at the end of each file under "Proposed,
needs a decision" and do not bind anyone.

- `sealing.md`: sealing a D2 protocol before any data read.
- `audits.md`: extraction, count rule, citation, accuracy, planted errors,
  G10 sample, severities, monthly report.
