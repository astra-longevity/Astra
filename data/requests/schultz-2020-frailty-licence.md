**Title:** Licence for the frailty data of Schultz et al. 2020?

Hello, we run Astra, an open ageing-research project (https://github.com/astra-longevity/Astra).
We would like to use the frailty data in this repository, from Schultz, Kane et al. 2020,
Nat Commun 11:4618 (doi:10.1038/s41467-020-18446-0), to train and test a mouse
biological-age measure. We would publish small derived tables, always citing the paper.
The repository has no licence file, so by default we may not reuse it.
Could you add a licence (for example CC BY 4.0) or give written permission?
Thank you for sharing the data and the FRIGHT/AFRAID models.
