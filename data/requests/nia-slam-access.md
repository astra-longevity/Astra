**Subject:** Request for per-mouse SLAM haematology, echocardiography and GTT data for an open ageing-research project

Hello Dr de Cabo, we run Astra, an open ageing-research project (https://github.com/astra-longevity/Astra) building a mouse biological-age measure and a simulation of organ ageing.
We already use the public SLAM deposit of Palliyaguru et al. 2021 (Cell Metab, Zenodo doi:10.5281/zenodo.5167639): census, survival with cause of death, NMR body composition, fasting glucose and body weight for 2 783 C57BL/6J and UM-HET3 mice, data cut 2019. We ask only for what that deposit does not hold:

1. **Haematology (ADVIA 120), per mouse and per bleed**, as used in Martinez-Romero et al. 2024 (Nat Aging), with the same mouse tags as the Zenodo census.
2. **Echocardiography, per mouse and per session**, for the subset scanned.
3. **Glucose (and insulin) tolerance tests, per mouse**, with test date and body composition closest to the test.
4. If available: frailty index, grip strength, rotarod and gait (MotoRater) per mouse and per session.
5. Death date and cause, or alive/censor status with last-seen date, for mice after the 2019 cut, so the existing lifespan records can be completed.

All untreated SLAM mice, both strains and both sexes, all ages. Data with the existing tags is enough; no new measurements or samples.

We would follow your terms: cite SLAM and the source papers, record the delivery date and file hashes, publish only derived tables (no raw per-mouse files) unless you allow otherwise, and share our results with your group before publication. A data use agreement is fine.

Thank you for running SLAM and for releasing the Zenodo data.
